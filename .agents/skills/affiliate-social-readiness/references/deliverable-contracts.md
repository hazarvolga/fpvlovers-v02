# Deliverable Contracts

Use these minimum structures. Improve existing documents in place and preserve useful verified material.

## `docs/affiliate-readiness-audit.md`

1. Executive verdict and evidence date
2. Baseline score table by rubric category
3. Current strengths with paths
4. Findings ordered P0/P1/P2 with evidence, risk, action, owner, and verification
5. Legal/trust route matrix: route, source status, content status, navigation visibility, live verification
6. Commercial-content inventory by canonical page and type
7. Technical SEO and CTA findings
8. Implemented fixes
9. Before/after score with explained deltas
10. Remaining application blockers and go/no-go recommendation

## `docs/affiliate-application-pack.md`

Provide ready-to-copy, honest answers for:

- website description
- audience description
- content types
- traffic acquisition strategy
- promotional methods
- program fit
- compliance statement
- affiliate disclosure statement
- brand-safety statement

Add a facts-to-verify table. Use bracketed placeholders for traffic, geography, email list size, social handles, launch date, or approvals not established by evidence. Include short and long versions where form limits commonly differ.

## `docs/social-media-playbook.md`

Include:

- positioning, voice, audience pillars, and guardrails
- role, cadence, formats, CTA, KPIs, and repurposing notes for Facebook, Instagram, YouTube Shorts, TikTok, X, and Reddit
- templates for new article, comparison, beginner tip, weekly deal, race/event, educational thread, and sponsor-safe posts
- disclosure examples for affiliate and sponsored posts
- 4-week repeatable publishing loop
- asset checklist and measurement taxonomy

Do not promise a fixed cadence the team cannot sustain. Separate recommended cadence from committed cadence.

## `docs/content-roadmap-affiliate.md`

Plan 90 days in three 30-day phases. For each content item include:

| Field | Requirement |
|---|---|
| Working title | Specific, credible, non-clickbait |
| Primary intent | Commercial investigation, transactional support, or informational |
| Affiliate potential | High/medium/low plus reason |
| Suggested products | Verified catalog items or clearly labeled product categories |
| Internal links | Existing canonical pages and planned cluster links |
| Page type | Review, comparison, buyer guide, checklist, tutorial, hub |
| Priority | P0/P1/P2 |
| Funnel stage | Discovery, evaluation, decision, retention |
| Dependency | Testing, catalog verification, imagery, legal review, or none |
| Success signal | Search impressions, qualified CTA clicks, email signups, or assisted navigation |

Include refresh rules and a cluster map. Avoid unsupported search-volume estimates.

## `docs/sponsor-media-kit-copy.md`

Include:

- one-line pitch
- sponsor pitch
- social bio
- About copy
- media-kit introduction
- audience fit without invented scale
- available editorially safe collaboration formats
- independence, disclosure, and brand-safety commitments
- inquiry CTA using only verified contact channels
- facts/assets still needed before publishing a media kit

Keep `what exists today` distinct from `future inventory`. Never label future placements as sold, available, or proven without confirmation.
