# GAP Raporlari Arsivi

Bu dizin, FPVLovers projesinin tarihsel GAP, denetim ve kapanis belgelerini saklar.
Aktif calisma raporu `docs/gap-reports/` kokunde tutulur; eski raporlar yeni durum
iddiasi olarak kullanilmamalidir.

## Dizinler

- `2026/`: Tarihli Markdown GAP, denetim ve devir belgeleri.
- `root/`: Daha once proje kokunde bulunan eski GAP raporlari.
- `tool/`: Arac bazli eski GAP raporlari.
- `evidence/`: Raporlari destekleyen makine okunabilir eski denetim ciktilari.
