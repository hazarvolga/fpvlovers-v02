## Cluster map

- Beginner system: drones -> starter kits -> radios -> goggles -> chargers.
- Video ecosystem: goggles -> DJI/Walksnail comparison -> antennas -> compatible VTX/cameras.
- Builder bench: soldering -> tools -> charger/battery safety -> component matcher.
- Racing: beginner practice -> gear checklist -> event coverage -> repair/spares.
- Long range: setup -> ELRS -> antennas -> GPS rescue/failsafe -> regulations.

## Publishing and refresh rules

1. Publish a methodology/testing label and disclosure before the first commercial CTA.
2. Link every new page to at least two useful existing pages and back from its hub/pillar.
3. Verify price and stock on publish day; timestamp price tables and avoid hardcoding unsupported discounts.
4. Refresh fast-moving digital video/radio pages quarterly; refresh evergreen safety pages when primary guidance changes.
5. Record search impressions, qualified CTA clicks, email signups, and assisted navigation. Do not optimize solely for raw outbound clicks.
