## Why This Matters

Outdated racing dates make a site look abandoned. For FPV pilots, stale event data is worse than an empty state because it can create false expectations around registration, travel, practice windows, and equipment preparation.

## Recommended Public UI Treatment

- Show an honest empty state when no upcoming races are available.
- Link users to official organizer channels for current registration information.
- Keep evergreen racing education visible below the empty state.
- Avoid concept-only dates in production UI.
- Mark archived race content clearly when it is historical.

## Pilot Takeaway

If you are preparing for a race, confirm the live calendar with the official organizer before booking travel, changing equipment, or planning qualification attempts.
