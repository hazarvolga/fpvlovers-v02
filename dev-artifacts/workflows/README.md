# Workflow Dosyaları

## Dify Workflows (workflows/dify/)
Dify v1.14.0 export JSON dosyaları.
Admin panelden: Settings → Workflows → Export.

Beklenen dosyalar:
- `content-generation.json` — İçerik üretim workflow
- `seo-optimization.json` — SEO optimizasyon workflow
- `affiliate-matching.json` — Affiliate eşleştirme workflow
- `retrieval-chain.json` — RAG retrieval zinciri

## Crawl4AI Configs (workflows/crawl4ai/)
Kaynak bazlı crawl konfigürasyonları.

Beklenen dosyalar:
- `reddit-config.json`
- `youtube-config.json`
- `rcgroups-config.json`
- `turkish-sources-config.json`
